# HAZE zombie rig candidates

Date: 2026-09-02

Scope: find better-looking, game-ready zombie characters with authored locomotion and combat animation for HAZE. This is research only. It does not change enemy AI, hit volumes, waves, controls, rendering code, or the production deployment.

The links below are creator, publisher, or platform license pages rather than asset aggregators. Asset pages and licenses can change, so save a copy of the terms shown when an asset is acquired. A browser game may ship a completed Product containing an asset, but must not expose the source GLB/FBX as a separately downloadable asset pack.

## Animation sources and supplements

These are useful when a good-looking mesh has a rig but lacks combat clips; they are not replacements for a zombie model.

- [Quaternius Universal Animation Library 2](https://quaternius.com/packs/universalanimationlibrary2.html) lists 130+ universal-humanoid animations, GLB/FBX/Blend formats, melee/armed combos, and zombie locomotion. The page says the assets are CC0 and free for commercial use, while 60–70% of the pack is completely free. It is a good source for retargeting Hotstrike, Kenney, or another humanoid mesh.
- [Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html) says Mixamo is free with an Adobe ID and its characters/animations are royalty-free for personal, commercial, and non-profit projects including video games. [Rigging help](https://helpx.adobe.com/creative-cloud/help/mixamo-rigging-animation.html) documents FBX upload and downloading applied animations. It is a practical animation supplement, but requires a login, FBX/GLB conversion, and a local license/archive record; do not redistribute the raw Mixamo files.
- [Quaternius Animated Zombie Pack](https://quaternius.com/packs/animatedzombie.html) is an older, very small CC0 option with an atlas-textured zombie and many animations in FBX/OBJ/Blend. It is worth testing only if the newer kit’s silhouettes are not a fit; it does not list glTF on the page.

## Candidates to treat as prototype-only

- [Zombie.glb — whynomakethings](https://whynomakethings.itch.io/zombieglb-3d-model-with-animations) is an unusually small glTF 2.0 with Idle/Hit/Run/Death and a statement allowing use in any project, but no formal commercial license was visible. Ask the creator for written commercial/web permission before shipping.
- [Gobkit Free Minions](https://gobkit.itch.io/gobkit-free-minions) is a high-quality CC0 GLB/animation technique (single atlas, idle/attack/dead), but its creatures are generic minions rather than zombies. It is a useful technical reference, not a visual recommendation for HAZE.

Do not use CC BY-NC models in a commercial HAZE build. Avoid asset-aggregator downloads, packs with no license, and pages that only offer a preview scene when the actual rig is hosted elsewhere.

## Recommended isolated trial

1. Preview PSX Zombies and Returner Reign side by side with the current Quaternius characters. Pick one visual language before importing more assets; PSX is the strongest horror fit, while Returner is the lowest-friction GLB/performance test.
2. Convert only the selected source to clean GLB if necessary. Keep one shared material/atlas, remove unused nodes, verify scale/grounding, and inspect Idle, Walk, Attack, Hit, and Death clips in Three.js `GLTFLoader`.
3. Keep the existing enemy entity authoritative. Swap only its visual child: one or two skinned GLB “hero” zombies nearby and directional impostor frames for the rest. This preserves the current game behavior and prevents a better asset from reintroducing crowd stutter.
4. Make three or four variants by palette, clothing/wound overlays, and head/prop silhouettes before buying multiple rigs. Bake those variants from the same rig into the existing 8-direction atlas so close and distant zombies match.
5. Record the source URL, download date, license text, and any conversion notes beside the local assets. Do not merge or deploy until the owner approves the visual/behavior comparison.

## Acceptance checks

- A close zombie reads as a zombie from front, side, and rear views and matches its impostor counterpart.
- Walk/attack/hit/death clips transition without foot sliding, T-pose flashes, or texture pop.
- Existing collision, damage, waves, death timing, score/proof events, controls, and camera framing are unchanged.
- Warm-cache crowded waves do not allocate a new texture/material/geometry per spawn, and rotation does not cause a visible one-second pause on a low-power profile.
- The asset’s license allows inclusion in a completed web game and the runtime build does not expose standalone source files.
