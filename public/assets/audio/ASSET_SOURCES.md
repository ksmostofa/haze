# HAZE audio assets

All runtime audio is stored locally and played through the existing `Audio` mixer. Procedural Web Audio remains the fallback if decoding fails.

## Kenney

- [RPG Audio](https://kenney.nl/assets/rpg-audio), CC0. License copy: `kenney/RPG-Audio-License.txt`.
- [Impact Sounds](https://kenney.nl/assets/impact-sounds), CC0. License copy: `kenney/Impact-Sounds-License.txt`.
- Used for footsteps, impacts, knife/metal accents, and creaks.

## OpenGameArt

- [20 Sword Sound Effects](https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes), CC0. Used for sword swings.
- [Zombies Sound Pack](https://lpc.opengameart.org/content/zombies-sound-pack), CC0. Used for randomized zombie vocals. The WAV source was converted to mono 22.05 kHz Ogg Vorbis for the browser build.
- [Forest Ambience](https://opengameart.org/content/forest-ambience), CC0. Used as the looping night-forest bed.
- [Player Hit (damage)](https://opengameart.org/content/player-hit-damage), CC0. Used for player damage.
- [Hurt Sound Effects](https://opengameart.org/content/hurt-sound-effects), CC0. Used as a hurt variation.

No Freesound or ZapSplat upload is used, because those libraries require checking each individual upload license.
