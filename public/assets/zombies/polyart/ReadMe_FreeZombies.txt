Free Zombies
------------

Textures:
 - All models use the same texture zcolors.png on Textures folder.

Pre-retargeted Animations :
 There are 2 type of skeletons:
 1) ZombieFemale
 2) ZombieMale

Inside 'animations-*' you will find the animations sets for each type of skeleton. These are already retargeted and manually adjusted for the best fit of each type.

Inside the 'rig-*' folder you can identify which skeleton uses each zombie by the prefex: Like 'ZombieFemale_*' or 'ZombieMale_*', etc.
